The pre-commit pipeline

Every git commit in applied projects triggers 4 gates — the commit is rejected if any fail.

1

ESLint

Checks for syntax and lint errors. Blocks the commit and prints the exact errors. Run npm run lint:fix to auto-fix.

2

Prettier Check

Ensures consistent code formatting. Run npm run format to auto-fix any formatting drift.

3

🛡️ Security Review /security-review plugin

Scans the staged diff for injections, XSS, hardcoded secrets, path traversal, and SSRF. Blocks on any finding.

4

🔍 Code Review /code-review plugin

Runs a focused code review on the diff using your ensemble of security, performance, a11y, and docs agents. Blocks if verdict is "Request Changes".
