nextjs-ts

Next.js App Router + TypeScript. Full-stack React with Server Components, Route Handlers, and Server Actions.

TSfullstackSSRRSC

When to choose this base

  • You want server-side rendering and React Server Components
  • You're building API routes alongside the UI (no separate backend)
  • You need first-class data fetching on the server (auth-gated, cached)
  • You're deploying to Vercel or any Edge-capable runtime

If you don't need SSR, see react-vite-ts. If your backend is separate, this might still be a good fit for the UI.

Apply command

bash scripts/apply.sh --base=nextjs-ts ../my-app
bash scripts/apply.sh --base=nextjs-ts --integrations=supabase,tailwind ../my-app
bash scripts/apply.sh --base=nextjs-ts --integrations=firebase ../my-app
bash scripts/apply.sh --preset=supabase-nextjs ../my-app
bash scripts/apply.sh --preset=t3-stack ../my-app
Scaffold Next.js first: 
npx create-next-app@latest my-app --typescript --app --tailwind --eslint
cd ..
bash scripts/apply.sh --base=nextjs-ts ./my-app

    "start": "next start",
    "lint": "next lint",
    "lint:fix": "next lint --fix",
    "format": "prettier --write .",
    "format:check": "prettier --check .",
    "test": "vitest",
    "test:coverage": "vitest run --coverage",
    "validate": "npm run lint && npm run format:check && npm run build && npm test -- --run",
    "review": "bash scripts/review.sh"
  }
}

Gotchas

  • Server vs Client boundary. Importing a Node-only library (Prisma, Firebase Admin) into a Client Component will break the build. The nextjs-conventions.md rule covers this.
  • Data fetching. Default fetch is cached forever. Use { next: { revalidate: N } } or cache: "no-store" deliberately.
  • Environment variables. Only NEXT_PUBLIC_* reaches the browser. Anything secret stays without the prefix.
  • The pre-commit hook runs next lint instead of the generic eslint .. If you customise the hook, mirror this.
  • Coverage targets from core/.claude/rules/testing.md (80%) may be hard to hit for Client Components — relax in your project's CLAUDE.md if appropriate.
