express-js

Node.js + Express, plain JavaScript. Classic REST API setup. This is also the base used by examples/express-demo/.

JSbackendRESTNode 25

When to choose this base

  • You're building a REST API and don't need TypeScript
  • You want fast iteration with no compile step
  • You're migrating an existing Express service and need the Claude brain on top

If you want types, jump to express-ts. If you want DI and modules, see nestjs.

Apply command

bash scripts/apply.sh --base=express-js ../my-api

With integrations:

bash scripts/apply.sh --base=express-js --integrations=supabase ../my-api
bash scripts/apply.sh --base=express-js --integrations=firebase,prisma ../my-api

Recommended package.json scripts after apply

{
  "scripts": {
    "start": "node src/index.js",
    "dev": "node --watch src/index.js",
    "test": "jest",
    "test:coverage": "jest --coverage",
    "lint": "eslint .",
    "lint:fix": "eslint . --fix",
    "format": "prettier --write .",
    "format:check": "prettier --check .",
    "validate": "npm run lint && npm run format:check && npm test",
    "review": "bash scripts/review.sh",
    "deps:audit": "npm audit --production",
    "deps:outdated": "npm outdated"
  }
}

Gotchas

  • The pre-commit hook expects npm run lint and npm run format:check to exit non-zero on issues. If you swap ESLint or Prettier, keep those exit semantics.
  • src/ is convention, not enforced. The Claude rules assume routes/middleware/services live there — adjust CLAUDE.md Architecture if you reorganise.
  • This base does not bundle Express itself. You install it (npm i express) — the base ships only Claude tooling and dev dependencies.

Smoke test after apply

cd ../my-api
npm install express
echo 'const app = require("express")(); app.get("/", (_, r) => r.send("ok")); app.listen(3000)' > src/index.js
npm run lint
npm run validate
