firebase-react

Vite + React + TypeScript + Firebase. Auth, Firestore, and Storage behind a fast SPA.

frontendfirebaseSPAv1

What it expands to

bash scripts/apply.sh --preset=firebase-react ../my-app
# equivalent to:
bash scripts/apply.sh --base=react-vite-ts --integrations=firebase ../my-app

When to use this preset

  • You're shipping a client-heavy SPA with realtime data
  • You want Google sign-in and a NoSQL store in minutes
  • You don't need server-side rendering
  • You're prototyping and Firebase's free tier covers you

If you need SSR, switch to nextjs-ts + firebase instead.

What lands

  • Base: react-vite-ts — Vite + React 18+, strict TS, jsx-a11y, react-hooks lint
  • Integration: firebase — firebase.md rule, env keys, Architecture paragraph

Environment variables

# Firebase Web SDK (browser-safe — security lives in firestore.rules)
VITE_FIREBASE_API_KEY=...
VITE_FIREBASE_AUTH_DOMAIN=...
VITE_FIREBASE_PROJECT_ID=...
VITE_FIREBASE_STORAGE_BUCKET=...
VITE_FIREBASE_MESSAGING_SENDER_ID=...
VITE_FIREBASE_APP_ID=...

Recommended workflow

  1. Scaffold Vite: npm create vite@latest my-app -- --template react-ts
  2. Apply the preset: bash scripts/apply.sh --preset=firebase-react ../my-app
  3. Install Firebase: npm install firebase
  4. Create a Firebase project and copy the Web SDK config into .env.local
  5. Write firestore.rules and storage.rules before shipping
  6. Test rules with the Firebase emulator: npx firebase emulators:start

Architecture sketch

my-app/
├── src/
│   ├── lib/
│   │   └── firebase.ts            App init + auth/firestore/storage getters
│   ├── hooks/
│   │   ├── useAuth.ts             Auth state + sign-in/out
│   │   └── useCollection.ts       Wrapped Firestore queries with cleanup
│   ├── components/
│   └── App.tsx
├── firestore.rules                Source of truth for read/write authorization
├── storage.rules
├── firebase.json                  CLI config (emulators, hosting)
└── .claude/                       From core + react-vite-ts base + firebase integration

Add Tailwind for styling

bash scripts/apply.sh --base=react-vite-ts --integrations=firebase,tailwind ../my-app

This is a common shape — Firebase backend + Tailwind UI for fast prototyping.
