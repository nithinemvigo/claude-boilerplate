t3-stack

The full T3 Stack — Next.js + TypeScript + Tailwind + tRPC + Prisma + NextAuth + Zod. Opinionated, type-safe, full-stack.

fullstackTSopinionated

What it expands to

bash scripts/apply.sh --preset=t3-stack ../my-app
# equivalent to:
bash scripts/apply.sh \
  --base=nextjs-ts \
  --integrations=tailwind,trpc,prisma,nextauth,zod \
  ../my-app
v2 status. trpc, nextauth, and zod ship in v2. v1 has tailwind and prisma. Running this preset before v2 lands will produce a clean error from apply.sh listing the missing integrations. For a partial T3 in v1, use: 
bash scripts/apply.sh --base=nextjs-ts --integrations=tailwind,prisma ../my-app

When to use this preset

  • You want the canonical T3 setup with zero decisions
  • You need end-to-end type safety from database to UI
  • You're building a SaaS-shaped app: auth, data, server actions, styling
  • Your team has agreed on this stack and wants to stop relitigating it

What lands

The result is the union of everything from nextjs-ts plus each integration. In short:

  • Base: nextjs-ts — Next.js App Router, strict TS, frontend rules, API route rules, ESLint with next/core-web-vitals
  • Tailwind: tailwind — utility CSS, class organisation rule
  • tRPC (v2): end-to-end typed RPC, procedure structure, error handling rule
  • Prisma: prisma — schema, migrations, singleton client
  • NextAuth (v2): Auth.js v5 for Next.js — providers, callbacks, JWT vs. database sessions
  • Zod (v2): runtime validation as the contract between layers

Environment variables (all combined)

# Database (Prisma)
DATABASE_URL=postgresql://...
DIRECT_URL=postgresql://...

# NextAuth (v2)
AUTH_SECRET=<random 32 bytes>
AUTH_URL=https://your.app
AUTH_GITHUB_ID=...
AUTH_GITHUB_SECRET=...
# (or whichever provider)

# Tailwind: no env vars
# tRPC: no env vars
# Zod: no env vars

Recommended workflow

  1. Scaffold Next.js: npx create-next-app@latest my-app --typescript --app --tailwind --eslint
  2. Apply the preset: bash scripts/apply.sh --preset=t3-stack ../my-app (in v2)
  3. Initialise Prisma: npx prisma init then write your schema
  4. Set up tRPC: create src/server/api/ with your router
  5. Configure NextAuth: src/server/auth.ts with providers
  6. Build features using Zod schemas as the source of truth for shapes

Equivalent manual command

If you want to deviate (e.g. swap Tailwind for vanilla extract):

bash scripts/apply.sh \
  --base=nextjs-ts \
  --integrations=trpc,prisma,nextauth,zod \
  ../my-app
