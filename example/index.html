🤖 Claude Universal Boilerplate Guide

This boilerplate provides a solid automation and agent "brain" layer that you can inject into any framework (React, Next.js, Node.js, TypeScript).

1. Porting to a New Project

To use this architecture in a brand-new Next.js, React, or TypeScript project, simply copy the essential brain files from this boilerplate root into your new project's root:

  • .claude/ - Contains your custom hooks, rules, slash commands, and agents.
  • .agents/ - Contains the master workflows (e.g., bug-fix.md, new-feature.md).
  • CLAUDE.md - The context injection file.
  • .editorconfig / .nvmrc - For environment standardization.

Note: You can completely delete the src/ directory from the boilerplate, as those are just demo files proving the security and lint hooks work!

2. Making Changes for Your Stack

Because the AI rules and agents are written entirely in Markdown, TypeScript and framework configurations just work out of the box.

The only changes you need to make are:

  1. Update CLAUDE.md: Change "Node.js" to "Next.js/React" and update the Architecture map to match your folders (like app/ or components/).
  2. Update package.json: Ensure your new project has basic linting configured if you want the PreToolUse hook to work properly.

3. Triggering Agent Workflows

We've included powerful e2e playbooks like new-feature.md and bug-fix.md. These use specific agents (like doc-writer and pr-description).

To execute a workflow inside Claude Code, simply prompt Claude:

Follow the workflow in .agents/workflows/new-feature.md to implement a user dashboard.

Claude will read the playbook, create a branch, write the code, run standard linting/formatting, pause for your pre-commit security review hook, and even generate a PR description for you.

4. The Pre-Commit Pipeline

By keeping the `.claude/settings.json` and `.claude/hooks/pre-commit-validate.sh` files, you get an automated pipeline.

Every time Claude tries to commit locally, or you manually run the script, it:

  • Runs ESLint & Prettier
  • Scans for Security Vulnerabilities (using Claude plugins)
  • Performs a Deep Code Review (using Claude plugins)
